## Audit and stop

Complete the frozen arms and compare mechanisms, conditions, independent caller
applicability, scoped negatives and actionable uncertainty. A local implementation
conclusion cannot stand for an unread application binding; an answered question is
a reviewer interpretation. Check actual lookup questions/results/remaining gaps,
retained conclusions and final decisions. Matching verdicts alone cannot pass.

Stop the study on a controller failure, unknown usage or changed frozen input;
preserve every paid attempt, including errors. No automatic repair, retry, effort
sweep, or restart under changed code. A security-quality disagreement is recorded
and audited without changing the remaining frozen arms. Close after source audit.

Measure actual input/output/cache, calls, provider time, active execution and native
validation overhead per arm/bundle. Input percentages are not acceptance gates.
Any pass is limited development evidence; the sixteen mixed main/eight reserved
claims and full-app review are outside this study. A failure is preserved before
another implementation attempt; unused ceilings do not authorize repairs.
