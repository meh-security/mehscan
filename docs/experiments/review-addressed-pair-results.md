## Supported findings and useful uncertainty

The three finalized Juice packages retain the two caller mechanisms, four
conditional cookie-authenticated mutation mechanisms and the fixed-configuration
redirect negative. Raw Terra has the same classifications in its saved drafts;
two image branches remain unconfirmed after the late answer described below.
All four policy results retain a concrete unavailable runtime sanitization
contract, without asserting either an exploitable hook or safe sanitization.

Cookie findings preserve the valid-cookie/browser-delivery premise and SameSite/
deployment limitations. Sol addressed also names an attacker-controlled same-site
origin as a possible qualifying context; it does not claim universal cross-site
cookie delivery. Erasure findings demonstrate deletion-request creation, not
completed deletion. Source-only review does not establish a deployed exploit.

Model calibration still differs: Sol uses medium for duplicate basket keys and
Terra uses high; both use high for checkout and medium for the cookie findings.
Those are severity differences, not additional mechanisms. The native redirect
also preserves a distinct outbound-request lead as an unvalidated adjacent
question, rather than changing its redirect verdict.

Terra raw gathers additional model and cookie-producer source before stopping.
That information is useful, even though the run does not finalize; it is not all
repeated exploration. One live directory request is normalized from
`references.path=frontend/src/app` to the same directory's `path_prefix`, with
original/effective arguments and one actual native query retained. This is a live
robustness receipt, not an isolated count of paid calls saved by that repair.

## The completion gap and corrected direction

Terra raw's fifth workspace turn settles the two image branches conditionally,
while continuing a shared cookie question for profile and erasure. Its final
sixth turn is therefore offered only profile and erasure. The context already
names both images under `settled_review_ids`, but the decision schema permits
only the two offered IDs. The final answer updates the shared question, whose
scope still covers all four mutations. Conservative invalidation then reopens
both image drafts. They cannot be reconfirmed in that response, and no seventh
workspace call is available.

This is an actionable state/view/output-authority mismatch. It is not evidence
of forgotten source, a malformed model response or a need to drop invalidation
guards. The failed arm's paid cost and all drafts remain; the two independent
Terra policy arms continued only after a recorded known-usage/no-drift audit.
No old state is rebound or silently finalized.

`closure-consumer-diagnostic.json` traces all six offers, decisions and answer
updates. A read-only hypothetical projection adds the two affected native
questions and exact prior results: compact input grows from 128,968 to 135,628
bytes, exceeding the frozen 131,072-byte cap. Keeping only the latest untruncated
question attempt plus count, and removing exact duplicate question/lookup-ID
strings, still leaves 131,757 bytes. These prototypes are not an implemented fix
or a repaired live result.

The next implementation should make the affected same-work consumers and their
previous results actionable together when a shared answer can invalidate them.
Retain source, applicability, dispute, session and budget guards. Measure a bounded
projection and, if needed, a modest explicit context allowance in fresh tests;
input is cheaper than another investigation, and semantic truncation is not a
good trade for a byte target. Do not offer every settled application claim or
automatically accept an old draft. See the [corrected implementation plan](../review-closure-and-evidence-plan.md#next-implementation-after-ar).

Keep the source format and qualified workspace state. Stop unchanged format/
speed reruns and full-app expansion while this controller gap is addressed
offline. A later confirmation must use fresh bindings and explicit allowances;
the closed raw Terra arm and all retired slots remain closed. Implementation-agent
source adjudication is useful evidence, not independent human gold.
