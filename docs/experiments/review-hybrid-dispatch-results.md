and an ordinary native-worker fragment. The workspace can retrieve deciding

## Corrections established by the fixtures

The native worker requires exact runtime limit bindings. Initially shortening its
configured timeout to the outer remainder rejects the fragment before inference.
The dispatcher now retains the bound worker settings and clamps actual provider
and native-command deadlines externally. This preserves native runtime validation.

Native import retains the original native drafts separately from registry draft
envelopes, so the exported decision can be checked against the worker's exact
output. Workspace source updates continue through existing privileged capture
operations; draft insertion is one bounded batch. Source-only captures on an
interrupted import do not constitute completed judgments.

The outer ledger reserves final slots for remaining units and advertises their
actual remaining credit before each call. Query batches stay charged when
rejected, received-byte overspend stays visible and partial provider counters
block both paths. No extra retry or model budget is created to repair a failure.
