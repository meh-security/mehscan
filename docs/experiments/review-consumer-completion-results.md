- Basket-item addition checks the first duplicate `BasketId` and persists the
  last, with registered identity/quantity middleware and model constraints
  inspected. The actual registration at `server.ts:427` is cited.
- Checkout selects the path basket and reaches effects without an ownership
  comparison; authentication and user-ID attachment are not treated as ownership
  enforcement. Its short citations include `server.ts:609–614`, which misses the
  actual checkout registration at `:604`. The registration was supplied, and the
  mechanism is supported, but the final evidence selection remains deficient.
- Both image branches, profile username mutation and deletion-request creation
  retain their own effects and caller conditions. The profile origin/referer
  expression is correctly treated as challenge bookkeeping, not a gate on the
  update. Erasure is described as creating a deletion request, not proving an
  immediate account deletion.
- All four cookie results require delivery of the victim's token cookie on the
  forged request. The shared proposition explicitly retains browser SameSite/site
  boundaries and excludes universal browser behavior or external deployment
  controls. The result is a conditional source finding, not a demonstrated
  universal cross-site POST bypass. A distinct image-fetch SSRF lead is retained
  without becoming another selected finding.

All **20 exported excerpts** match physical source byte ranges exactly. The JSON
review package regenerates identically without database mutation; all six drafts
are current and native finalization succeeds. These checks do not repair the
checkout citation or certify the entire operation/application. This is an
implementation-agent source audit, not independent human gold.
