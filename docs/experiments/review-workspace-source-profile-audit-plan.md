## Evidence and stopping

Record query purpose, origin, returned evidence, whole-file hashes, CLI calls,
query units, JSON/source bytes, acquisition wall time and preparation/packet time.
Measure actual delivery limits and remaining source questions. No old verdict,
answer, proposition or applicability assertion enters a fresh reviewer context.

Stop a profile as unready if materialization omits requested source, source or
scope changes, either packet differs, or a provider attempt is reserved. A failed
profile does not invalidate supported source or the independently declared caller
profile. Do not repair a failed attempt into a paid result or silently enlarge it.

Readiness of the caller profile means transport/source delivery only. The physical
storage/post-hook-key qualification and installed-hook uncertainty remain material;
no safe verdict follows from having read authentication source. Manual choice of
the intervention and prior model/audit work remain costs. If a production selector
requires another complete investigation per claim, retain this as assisted
diagnostic evidence, not a practical efficiency claim.

After closure, choose implementation from the measured boundary: a common explicit
source channel if eight windows must be compared, or an explicitly different
four-window intervention. Do not launch unchanged AD, a mixed paid package or a
