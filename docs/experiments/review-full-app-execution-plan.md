## Evaluator-only quality criteria

Freeze exact selected native questions and rule/path/anchor catalog separately
from model input. Check mechanisms and actual effects, caller/check/effect
applicability, sufficient local proof, scope/assumptions, severity, useful leads
and actionable uncertainty. More source inspected is not automatically better;
a missing decisive transformation is not excused by a cheap or confident answer.
Do not force unknowns into dismissals or treat all budget-limited unread source
as an unavailable external dependency.

Audit every consequential disagreement: verdict, materially different mechanism,
assumption, impact/severity, missing applicability, or lost distinct lead. Check
known source mechanisms/controls without requiring historical labels. For claims
that agree as negative in all four available complete results, choose up to two
per rule by ascending SHA-256 of `BB-20261028-quality:<review_id>`. Apply this
precommitted method to all represented negative rules, in addition to the known
mechanism checks; missing results are never agreement. Mask model/workflow labels
in worksheets where practical, while acknowledging the implementation agent has
observed dispatch/progress. This is not independent gold.

Preserve physical source fidelity separately from relevance to the asserted
caller. Evaluator-only reads never become retroactive provider evidence. Keep
original verdicts/conditions and report adjudication alongside them. Count every
selected ID, including draft, absent, invalidated, unfinished or cap-censored work;
do not confuse packet captures with calls, source validation with correctness,
or several scanner markers with several distinct vulnerabilities.

Stop further paid work on source/runtime/provider drift, unknown accounting or a
shared execution defect. Preserve all useful partial results. A semantic weakness
does not erase independent supported findings or every mode. Prefer the cheaper
package when both satisfy the selected evidence boundary; keep a more expensive
mode when it buys material quality. No universal winner, full-app promotion or
second-application run follows automatically from BB.
