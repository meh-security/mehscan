# Mehscan 0.17.0

## Features

- Prepare staged source folders and archives for review with a stable repository key and reusable local review memory.
- Share review memory through a self-hosted Turso server over HTTPS. Engineers and configured AI reviewers can publish final decisions with their rationale and source evidence for later scans.

## Bug fixes

- Remove the repeated CWE coverage level from new reports while preserving existing review-memory fingerprints.
