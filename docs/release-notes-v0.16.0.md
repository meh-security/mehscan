# Mehscan 0.16.0

## Features

- Add Ruby source reviews with selected Rails, process, file, HTTP and object-loading evidence.
- Add a call-only allowance for named work plans that use a trusted local reviewer.

## Bug fixes

- Report source-review jobs and distinguish imported evidence from executed lookups.
- Report native admission independently of review coverage.
- Document the six-stage repository review and return a clear error when a saved audit needs a bundle directory.
