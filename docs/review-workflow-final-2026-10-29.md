## Route by the deciding relationship

| Situation | Working choice |
| --- | --- |
| Complete local SQL binding/construction or bounded API contract | Native closure; no mandatory caller sweep |
| Compatible claims sharing a check or implementation | One workspace investigation, separate caller applicability and verdicts |
| Authorization, credential or workflow question | Inspect the relevant subject/object/check-to-effect relationship and independent guards |
| Version-specific token/credential semantics | Load `token-review` from the skill's guidance catalog; supply or retrieve the deciding implementation, with version/resolution limits |
| Consequential unresolved facts or unsupported conclusions | Selective evidence-and-flow review using the same source snapshot |

File/category proximity alone is not grouping. A local owner predicate can be valid while identity provenance is unresolved. A selector primitive is not automatically a vulnerability without its security effect. An adjacent workflow mechanism is retained as a separate lead/finding instead of replacing a valid scoped negative. Category references already express these distinctions; use relevant guidance rather than growing the base prompt for every observed mistake.

The targeted reviewer receives the proposed conclusion, supporting source, the deciding question and lookup access. It checks **claim → operation → input/identity → transformation/guard → effect → conclusion**. Select consequential uncertainty, risky confident negatives, version-dependent assumptions, unsupported impacts and package contradictions; sample otherwise unflagged outcomes when evaluating selection quality. A useful amendment can correct scope or impact without changing a verdict. Keep original outcomes, amendments, source and unresolved questions separate until normal validation/revalidation accepts a change. Sol remains an optional targeted comparator, not a mandatory adjudicator.

## Evidence behind the choices

- Full stable Terra native reviewed 116 claims for $1.5627648 versus $3.410960 in the saved dynamic run. The controlled slice also showed substantial cache savings. Full-run input/time increased, so the win is cheaper repetition, not less investigation.
- The 68-claim Terra reviewer diagnostic cost $0.569060 extra, or $2.1318248 with the saved base. It found useful mechanisms and also retained/introduced errors. Hence selective review and source audit, not automatic acceptance of reviewer verdicts.
- JWT guidance/source combinations all completed 13 claims and corrected the expiry premise, including control. Combined used 8 calls/$0.1219762 versus control's 10/$0.136968. Keep guidance plus relevant prepared source as a scoped option, without claiming guidance alone caused the improvement.
- Real receipt reuse completed both consumers but cost $0.139438 versus direct $0.127680. Keep the bounded API; no default helper or memory layer is justified.
- The final concurrency check completed 13 claims in both arms. Serial: 8 calls/$0.1305212/116.789s. Two workers: 10 calls/$0.1671024/86.487s. Two workers were 25.9% faster for 28.0% more review cost; this misses the price-focused promotion target. Keep it as an explicit speed option.
- Fresh PyGoat: all 201 claims completed in 28 native bundles/80 calls for $1.3935644, with 60.338% cached input. Seven selective workspace reviews added $0.1738070; five avoidable uncertainties closed as scoped negatives. Two proposed encoding findings established only title-script disruption, so their security promotions were rejected. Total measured package $1.5673714; no unknown receipts. This supports carrying implementation-bound source into follow-ups and auditing security impact, not universal workspace review or automatic acceptance.
- OrchardCore: all 537 base claims were assembled and source-validated after explicit offline recovery, in 39 native bundles/167 receipted calls for $4.2248608, with 69.466% cached input. The 20-claim filesystem follow-up exported 17 judgments for $0.3148500 known plus one unpriced aborted call. The audited diagnostic package retains 14 issue decisions across three conditional mechanisms, 343 scoped negatives and 180 uncertainties. Preserve shared implementation closure and native local contracts; fix output/recovery gaps and selectively audit actual security effects before promotion. Historical labels and closure counts are not ground truth.

These are published Standard API equivalents, not invoices. Single small comparisons have model/cache variation. Partial or unknown-receipt arms are not cheaper complete packages. Source validation establishes evidence integrity, not semantic accuracy.
