# Review workflow: current evidence and decisions

The practical direction is a hybrid selected by deciding work, with packet
placement chosen separately from logical investigation. No whole-app efficiency
or quality win has been established.

| New knowledge | Evidence | Consequence |
| --- | --- | --- |
| Useful grouping exists, but singleton comparisons overstate its advantage over native defaults | L2 saves five uncapped calls on SQL/deluxe; both arms are workspace. Native already defaults to 20 reviews | Keep those shared mechanisms; use ordinary native batching as the actual comparator |
| Uniform workspace is not a demonstrated faster replacement | AI: Sol native ten calls/186.130 active seconds, workspace eleven/216.744 | Route local SQL/API work natively and select workspace where retained relational state helps |
| Matching verdicts can hide different proof depth | AI native reads the role-to-signed-credential chain; workspace stops earlier; severity differs | Audit mechanisms, conditions, caller proof and severity separately from labels |
| The observed NoSQL slowdown is evidence navigation | Native four calls versus both workspaces six; query units remain; no lost earlier fact is shown | Treat test discovery as a targeted correction, not a generic memory failure |
| Persistent state has useful demonstrated behavior | AA closes local callers separately while retaining a conditional fact and the outstanding external question; AH exports exact qualifications | Preserve state/package fidelity without claiming it causes savings |
| Routing can recreate conversation overhead | AJ's 22 claims produce twelve units from ten original native packets | Show fragmentation; do not equate a logical investigation with a required conversation |
| Fair budgets and complete assembly now work | AK uses connected original-bundle allowances and ordinary native validation-only review, then reassembles every original bundle | Splits grant no new credit; unknown usage blocks further paid calls; keep native results and workspace qualifications exact |
| A packet may contain more than one independent investigation | New explicit `packet_batch` selection retains separate caller/check questions and warns against transferring verdicts | Co-locate a local peer with an already selected workspace packet when a separate native fragment would add avoidable context |

Native is the practical initial choice for complete SQL constructions, cookie
flags and local parser/API decisions. This is not a proven SQL engine ranking.
Workspace remains appropriate for selected shared dependencies, different caller
conditions, check-to-effect relationships and partial closure. Co-location does
not turn a wallet selector into the deluxe operation or an external policy into
the inspected local sanitizer.

Source/profile selection is still manually assisted. Preparation, planning,
provider calls, output, actual model/active time and assembly all count. Input
reduction, shorter responses, fewer groups and lower configured ceilings are not
success criteria. Saved implementation-agent audits are not independent human gold.

The next fresh comparison uses packet placement to avoid the fragmentation already
identified, verifies actual native/workspace packets before dispatch and evaluates
the whole mixed package. Keep Sol native versus Sol hybrid primary, with Terra
6.1 medium hybrid supplementary. No old paid run or retired allowance resumes.
