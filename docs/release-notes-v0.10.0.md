# Mehscan 0.10.0

## Features

- Add optional Fast and Full second-pass reviews, scoped to findings, dismissals or unresolved items.
- Export review comparisons and training-label candidates with linked evidence.
- Expand C/C++ and Rust memory, ownership and lifetime review.
- Broaden Python credential, Rust state and HTTP, and Go identity review.

## Bug fixes

- Reduce noisy hashing, token and filesystem review candidates.
- Respect Rust source-module conditions and exclude additional test, spec and sample conventions.
- Preserve review evidence and second-pass exports when recovering interrupted work.
- Reduce repeated source analysis and improve cache reuse during AI review.
