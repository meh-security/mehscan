# Mehscan 0.15.0

## Features

- Run Value first and continue into Comprehensive for broader coverage, carrying forward validated decisions and the remaining review allowance.
- Set review budgets or coverage goals, rank investigations, and report unfinished checks.
- Reuse source-bound review knowledge through local Turso snapshots and authenticated sharing.
- Group findings by repair point and keep passive models and generated browser bundles available for targeted lookup.

## Bug fixes

- Preserve completed results during interrupted reviews and keep unanswered work visible.
- Improve startup on large repositories and handle repository-root lookup filters.
- Improve Python ORM query coverage and reduce duplicate candidates.
